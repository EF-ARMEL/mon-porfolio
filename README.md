# Portfolio — Ettien Franck Armel

Un portfolio moderne, performant et interactif développé en pur HTML, CSS et JavaScript.
Ce projet met en valeur mes compétences en développement web Full Stack tout en offrant une expérience utilisateur (UX) haut de gamme.

## ✨ Fonctionnalités & Design Premium

- **Dark Mode Riche** : Palette de couleurs sombres rehaussée par un arrière-plan animé (« Ambient Blobs ») ajoutant de la profondeur.
- **Effet Magnétique 3D (Tilt)** : La photo de profil et les cartes de projets réagissent dynamiquement et s'inclinent en 3D selon les mouvements de la souris.
- **Animations en Cascade (Staggered Reveals)** : Les badges de compétences et les cartes projets apparaissent de manière fluide et séquentielle lors du défilement.
- **Micro-interactions Avancées** : Barre de progression de défilement intégrée à la navigation, effets de survol de type "Glassmorphism" sur les éléments interactifs.
- **Optimisation SEO & Accessibilité** : Balises meta (`theme-color`, `description`), textes alternatifs `aria-label` sur les liens sociaux et structure CSS sémantique.

## 📂 Structure du projet

```text
portfolio/
├── index.html       ← Structure sémantique et contenu principal
├── style.css        ← Design, animations CSS, Custom Properties
├── script.js        ← Intersection Observer, Vanilla Tilt 3D, Scroll Progress
├── assets/          ← Fichiers médias (Images, CV PDF)
└── README.md        ← Documentation
```

## 🚀 Stack Technique

- **HTML5** (Sémantique & Accessible)
- **CSS3** (Variables CSS, Flexbox/Grid, Keyframes, Backdrop-filter)
- **Vanilla JavaScript ES6+** (Manipulation du DOM sans bibliothèques lourdes tierces)
